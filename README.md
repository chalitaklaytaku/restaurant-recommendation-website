# 🍽️ นางรอง ลองชิม (Nang Rong Secret Taste)
### ระบบเว็บไซต์แนะนำร้านอาหารลับในอำเภอนางรอง จังหวัดบุรีรัมย์
*(โครงสร้างแบบ Multi-Page Architecture แยกหน้าการทำงานแต่ละหน้าอย่างชัดเจน)*

โครงการพัฒนาเว็บไซต์แนะนำร้านอาหารลับและของอร่อยท้องถิ่นในเขตอำเภอนางรอง จังหวัดบุรีรัมย์ เพื่อส่งเสริมเศรษฐกิจชุมชนและอำนวยความสะดวกแก่นักท่องเที่ยวและประชาชนในการค้นหาร้านอาหาร

---

## 🚀 วิธีการเปิดใช้งานเว็บไซต์ (Quick Start)

ระบบนี้สร้างขึ้นในรูปแบบ **Multi-Page Web Application** ที่ทำงานได้ทันทีโดยไม่ต้องติดตั้ง Server หรือ Dependency ใดๆ:
1. เข้าไปที่โฟลเดอร์โครงการ `C:\Project`
2. **ดับเบิลคลิกที่ไฟล์ `index.html`** หรือไฟล์ **`เปิดเว็บไซต์_นางรองลองชิม.bat`**
3. สามารถคลิกเปลี่ยนหน้าผ่านเมนูด้านบน (Navbar) เพื่อสลับไปยังหน้าต่างๆ ได้อย่างอิสระและชัดเจน

---

## 📂 โครงสร้างการแยกหน้าเว็บไซต์ (Separate Pages Structure)

ระบบได้ทำการแยกหน้าหลักออกจาก `index.html` เป็นไฟล์เฉพาะแต่ละหน้า ดังนี้:

| ไฟล์หน้าเว็บ | ชื่อหน้า | หน้าที่และฟังก์ชันการทำงาน |
| :--- | :--- | :--- |
| **`index.html`** | **หน้าแรก (Home)** | แบนเนอร์ต้อนรับ, ช่องค้นหาเร่งด่วน, ทางลัดหมวดหมู่อาหาร, ร้านลับไฮไลท์ประจำสัปดาห์, แผนที่ย่อ อ.นางรอง |
| **`restaurants.html`** | **สำรวจร้านอาหาร (Explore & Search)** | ค้นหาแบบ Real-time, ตัวกรองหมวดหมู่, ตัวกรองช่วงราคา, ตัวกรองระดับความลับ, ตัวกรองสถานะเปิดอยู่, การเรียงลำดับ |
| **`restaurant-detail.html`** | **รายละเอียดร้านเดี่ยว (Detail View)** | แสดงข้อมูลร้านตามรหัส `?id=...`, แกลเลอรีภาพ, ประวัติร้าน, เมนูแนะนำพร้อมราคา, แผนที่ปักหมุดเฉพาะร้าน, ปุ่มโทร, ปุ่มนำทาง Google Maps, ระบบรีวิวและให้ดาว |
| **`map.html`** | **แผนที่ร้านลับเต็มจอ (Interactive Map)** | แผนที่ Leaflet แสดงหมุดร้านอาหารทั้งหมดในอำเภอนางรอง, กรองหมวดหมู่บนแผนที่, แถบ Sidebar ค้นหาและคลิกเพื่อซูมหมุด |
| **`survey.html`** | **แบบประเมินวิจัย (Satisfaction Survey)** | แบบสอบถาม Likert Scale 5 ระดับ (10 ข้อ 5 ด้าน), แดชบอร์ดวิเคราะห์สถิติ ($\bar{X}$ และ S.D.), กราฟ Chart.js, ตารางค่าสถิติสำหรับบทที่ 4, ปุ่มดาวน์โหลด Excel CSV และปุ่มพิมพ์รายงาน |
| **`suggest.html`** | **แนะนำร้านลับใหม่ (Crowdsourcing)** | แบบฟอร์มให้คนในพื้นที่หรือนักท่องเที่ยวส่งข้อมูลร้านลับที่อยากให้ทีมงานไปรีวิว พร้อมแสดงรายการร้านที่เสนอเข้ามาล่าสุด |
| **`about.html`** | **ข้อมูลโครงงานวิจัย (Chapter 1 Docs)** | แสดงรายละเอียดเนื้อหาบทที่ 1 อย่างเป็นทางการ (ความเป็นมา, วัตถุประสงค์ 2.1-2.3, สมมติฐาน, ขอบเขต 4.1-4.4, ประโยชน์ 5.1-5.5, นิยามศัพท์เฉพาะ 6.1-6.4) |

## 🛠️ โครงสร้างไฟล์และโค้ดเบื้องหลัง (Assets & Scripts)

```text
C:\Project\
│
├── index.html                   # หน้าแรก
├── restaurants.html             # หน้ารวมและค้นหาร้านอาหาร
├── restaurant-detail.html       # หน้ารายละเอียดร้านเดี่ยว (?id=X)
├── map.html                     # หน้าแผนที่พิกัดร้านลับเต็มจอ
├── survey.html                  # หน้าแบบประเมินความพึงพอใจและสถิติบทที่ 4
├── suggest.html                 # หน้าแนะนำร้านลับใหม่
├── about.html                   # หน้าข้อมูลโครงงานวิจัยบทที่ 1
├── เปิดเว็บไซต์_นางรองลองชิม.bat # ทางลัดดับเบิลคลิกเปิดเว็บทันที
│
├── css\
│   └── style.css                # ดีไซน์โทนสีอบอุ่น, Badges, Glassmorphism และ Print Stylesheet
│
├── js\
│   ├── data.js                  # ฐานข้อมูลร้านอาหาร 12 ร้านจริงใน อ.นางรอง, คำถามวิจัย, สถิติตัวอย่าง
│   └── common.js                # ฟังก์ชันส่วนกลาง (Navbar, Active Link, ระบบร้านโปรด Favorite, สุ่มร้านลับ)
│
└── README.md                    # เอกสารคู่มือโครงการ
```

## 🎯 ความสอดคล้องกับเล่มรายงานวิจัย (บทที่ 1 ถึง บทที่ 5)

* **บทที่ 1 (บทนำ):** ข้อมูลตรงตามที่ระบุไว้ในหน้า `about.html` ทุกประเด็น
* **บทที่ 3 (วิธีดำเนินการวิจัย):** สามารถนำโครงสร้างของหน้าต่างๆ (Multi-Page Architecture) และผังงานระบบไปใช้อธิบายในบทที่ 3 ได้อย่างเป็นระบบ
* **บทที่ 4 (ผลการวิเคราะห์ข้อมูล):** เข้าไปที่หน้า `survey.html` จะมีแดชบอร์ดคำนวณค่าเฉลี่ย ($\bar{X}$) และส่วนเบี่ยงเบนมาตรฐาน (S.D.) พร้อมตารางสรุปที่สามารถคัดลอกหรือสั่งพิมพ์/ดาวน์โหลดไฟล์ Excel CSV ไปใช้งานได้ทันที
* **บทที่ 5 (สรุป อภิปรายผล):** สรุปผลความพึงพอใจโดยรวมว่าอยู่ในระดับ "มากที่สุด" สอดคล้องตามสมมติฐานการวิจัย
